# سكشن | لوحة المعيد

تطبيق ويب تقدمي لإدارة المقررات والسكاشن وقوائم الطلاب بواجهة عربية تدعم اتجاه الكتابة من اليمين إلى اليسار. تحفظ النسخة الحالية البيانات في المتصفح باستخدام `localStorage`.

## التشغيل

يتطلب المشروع Node.js ‏20.19+ أو 22.12+.

```sh
npm ci
npm run dev
```

للتحقق من بناء الإنتاج وتسجيل عامل الخدمة محليًا:

```sh
npm run build
npm run preview
```

يُتاح التثبيت والعمل دون اتصال في المتصفحات التي تدعم تطبيقات PWA بعد تحميل نسخة الإنتاج لأول مرة عبر HTTPS أو localhost.

## استيراد الطلاب

افتح سكشنًا ثم اختر **استيراد من إكسيل**. يدعم التطبيق أول ورقة من ملف `.xlsx`، أو ملف `.csv` بترميز UTF-8. يجب أن يحتوي الصف الأول على عناوين الأعمدة مثل «الاسم» و«الكود» أو `Name` و`ID`. تظهر نافذة لاختيار الأعمدة حين يتعذّر تحديدها تلقائيًا. تُتخطى الصفوف التي ينقصها الاسم أو الكود، والأكواد المكررة داخل السكشن. احتفظ بعمود الكود كحقل نصي في إكسيل للحفاظ على الأصفار في بداية الأكواد.

يحدد `src/services/storage.ts` واجهة التخزين التي يمكن تنفيذها لاحقًا باستخدام Firestore.
